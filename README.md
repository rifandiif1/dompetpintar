# DompetPintar v3.0 - Mudah Dipahami & Bisa Tambah Rasio Sendiri

Aplikasi pengelola gaji dan keuangan harian yang dirancang ramah untuk orang awam, dilengkapi panduan langkah demi langkah di dalam aplikasi serta fitur **Tambah/Ubah Pos Rasio Sendiri**.

## Fitur Unggulan v3.0
- **Bisa Tambah Rasio Sendiri:** Selain 5 rasio utama (0.2 Pokok, 0.4 Tagihan, 0.2 Investasi, 0.1 Dana Darurat, 0.1 Shodaqoh), pengguna bisa menambah pos baru beserta ikon, warna, dan angka pengali rasionya sendiri.
- **Tombol Seimbangkan Otomatis ke 1.0 (100%):** Menghitung proporsi otomatis bagi pengguna awam.
- **Simulasi Pembagian Gaji Langsung:** Melihat hasil perkalian gaji sebelum disimpan.
- **Pos Pengeluaran (Rencana Belanja) & Target Tabungan Impian.**
- **GitHub Actions Ready (JDK 21 + Android SDK Preinstalled):** Bebas error `Failed to find package 'tools'`.
