# DompetPintar Pro v2.0 - Auto-Budget Gaji & Pos Pengeluaran

Aplikasi manajemen keuangan Android & Web dengan fitur pembagian gaji otomatis (`0.2 Pokok`, `0.4 Tagihan`, `0.2 Investasi`, `0.1 Dana Darurat`, `0.1 Shodaqoh`) serta manajemen **Pos Pengeluaran Spesifik**.

## Cara Build Menjadi APK di GitHub Actions
1. Upload seluruh isi folder ini ke repository GitHub Anda.
2. Buka tab **Actions** -> workflow **Build Android APK** akan berjalan otomatis.
3. Unduh **DompetPintar-Pro-APK** pada bagian **Artifacts** setelah proses build selesai.
