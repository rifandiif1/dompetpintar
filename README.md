# DompetPintar v4.0 - Auto-Budget Gaji, Custom Ratio & CamScanner Struk

Aplikasi pencatat keuangan pribadi dengan fitur **Scanner Struk Belanja ala CamScanner** (Magic Color, Hitam-Putih Dokumen, Grayscale, Putar 90°, & Penajam Teks otomatis).

## Fitur Utama v4.0
- **CamScanner Struk Belanja:** Ambil foto struk langsung dari kamera/galeri, otomatis dijernihkan sehingga kertas tampak putih bersih dan tulisan tajam.
- **Auto-Budget Rasio Gaji & Tambah Rasio Sendiri:** Default 0.2 Pokok, 0.4 Tagihan, 0.2 Investasi, 0.1 Darurat, 0.1 Shodaqoh + bebas tambah pos baru.
- **Pos Pengeluaran (Rencana Belanja) & Target Tabungan.**
- **Siap Build APK di GitHub Actions (Java 21 + Android SDK).**
